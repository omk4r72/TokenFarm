# TokenFarm 🧠

**TokenFarm** is a decentralized yield farming and staking platform built on the Stellar Testnet. It allows users to stake their tokens, earn rewards, and swap between different tokens with a simple and intuitive interface. The platform simulates blockchain interactions and demonstrates DeFi concepts for hackathon purposes.

---

## Features

- **Wallet Integration**  
  Connect using Freighter Wallet or manually enter a Stellar public key.

- **Account Overview**  
  Shows total balance, minimum reserve, staked tokens, and available balance.

- **Token Staking**  
  Stake your tokens (STELLAR, USDC, BTC, ETH, SOL) and earn simulated rewards.

- **Token Swapping**  
  Swap between supported tokens with a demo 5% fee.

- **APY Calculation**  
  Calculates estimated APY for staked tokens based on preset rates.

- **Ledger / Recent Activity**  
  Tracks your staking and swapping actions with timestamp and demo transaction hash.

- **Interactive Rewards Chart**  
  Visual representation of estimated rewards over time.

- **Toasts / Notifications**  
  Shows real-time feedback on staking, swapping, and wallet actions.

---

## Technologies Used

- **Frontend:** React, Chart.js, React Icons  
- **Styling:** CSS  
- **Blockchain Simulation:** Stellar Testnet (Horizon API)  
- **Wallet Support:** Freighter Wallet & Manual Public Key
